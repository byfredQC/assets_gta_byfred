# assets_gta_byfred

Addon Blender : catalogue de 35 889 vignettes GTA V, import frais depuis le jeu sans collision, pinceau, favoris, récents, tags YTYP et aperçu CodeWalker.

## Téléchargement et installation

Télécharge **assets_gta_byfred.zip** dans les [Releases](https://github.com/byfredQC/assets_gta_byfred/releases). Le ZIP contient l’addon complet, ses sources, les vignettes et le guide d’utilisation.

Désactive l’ancien addon GTA Photo Props avant d’installer et activer assets_gta_byfred. Redémarre ensuite Blender.

Version 0.4.3 — testée avec Blender 5.2.3. Sollumz avec support natif GTA et une installation locale compatible de GTA V sont nécessaires. CodeWalker est requis uniquement pour son aperçu externe.
